Sfondo interattivo per pagina

Il link deve aprire direttamente l’immagine. I link PhotoToURL / Google Drive “non pubblici” non funzionano. Meglio: carica il file su GitHub in images/bgs/ e qui scrivi images/bgs/home.png. Copertura scura: 10–20%.

I video non stanno nel piano gratis. Caricali nella cartella videos/ su GitHub, poi scrivi qui il percorso.

Esempio URL sito: https://gamingrelaxofficials.it/videos/coding-lofi.mp4 — prima carica il file su GitHub. Copertura scura: tieni 25–40% se vuoi vedere bene foto o video.
